PART 1 — LOGIN (KEEP EXISTING UI, WIRE REAL API)
═══════════════════════════════════════════════
Keep login screen design exactly as is.
Only replace mock auth with real Zabbix API call.

On "Sign In" button tap:

Step 1 — Check server URL configured:
  Read "zabbix_server_url" from FlutterSecureStorage
  If empty → show error:
  "Configure Zabbix server URL in Settings first"

Step 2 — Authenticate:
POST {serverURL}/api_jsonrpc.php
{
  "jsonrpc": "2.0",
  "method": "user.login",
  "params": {
    "username": "{username}",
    "password": "{password}"
  },
  "id": 1
}

Success → store:
  "zabbix_auth_token" → result (session token)
  "zabbix_username" → username
  "login_timestamp" → now

Failure → inline error:
  -32602 → "Invalid username or password"
  Network → "Cannot reach Zabbix server"
  Other → "Authentication failed. Try again."

Step 3 — Fetch user profile + role:
POST {serverURL}/api_jsonrpc.php
{
  "jsonrpc": "2.0",
  "method": "user.get",
  "params": {
    "output": ["userid","username","name",
               "surname","roleid","type"],
    "filter": {"username": ["{username}"]}
  },
  "auth": "{session_token}",
  "id": 2
}

Map Zabbix type to app role:
  type 1 (User) → OPERATOR
  type 2 (Admin) → DEVOPS
  type 3 (Super Admin) → ADMIN

Store:
  "user_role" → "ADMIN" | "DEVOPS" | "OPERATOR"
  "user_display_name" → "{name} {surname}"
  "user_id" → userid

Step 4 → Navigate to Dashboard

Session management:
  On app launch → check "zabbix_auth_token" exists
  → yes: skip login, go Dashboard
  → no: go Login
  On API error -32602 → token expired → 
    clear all storage → redirect to Login
  Logout → call user.logout + clear storage

PART 3 — ALL ZABBIX DATA APIs (REAL)
═══════════════════════════════════════════════
All data calls use API Token from Settings:
Header auth: "zabbix_api_token"

DASHBOARD (refresh every 30s):

1. Problems:
method: "problem.get"
params: {
  "output": ["eventid","objectid","severity",
             "clock","name","acknowledged"],
  "selectAcknowledges": "count",
  "sortfield": ["severity","clock"],
  "sortorder": ["DESC","DESC"],
  "limit": 100
}

2. Hosts:
method: "host.get"
params: {
  "output": ["hostid","host","name",
             "available","status"],
  "selectInterfaces": ["ip"],
  "filter": {"status": 0}
}
available: 1=UP, 2=DOWN, 0=Unknown

3. Severity counts from problems:
severity: 0=Not classified, 1=Info, 2=Warning,
          3=Average, 4=High, 5=Disaster

4. Services/SLA:
method: "service.get"
params: {
  "output": ["serviceid","name","status","goodsla"]
}

INCIDENTS SCREEN:
method: "problem.get"
params: {
  "output": "extend",
  "selectAcknowledges": "extend",
  "selectTags": "extend",
  "recent": true,
  "sortfield": ["severity","clock"],
  "sortorder": ["DESC","DESC"]
}

Get trigger+host per problem:
method: "trigger.get"
params: {
  "output": ["triggerid","description","priority"],
  "selectHosts": ["hostid","host","name","interfaces"],
  "selectItems": ["itemid","name","lastvalue","units"],
  "triggerids": ["{objectid}"]
}

Acknowledge:
method: "event.acknowledge"
params: {
  "eventids": ["{eventid}"],
  "action": 6,
  "message": "Acknowledged via Poulina AI OpsHub"
}

INFRASTRUCTURE:
method: "host.get"
params: {
  "output": "extend",
  "selectInterfaces": ["ip","type","main"],
  "selectGroups": ["groupid","name"],
  "selectTriggers": "count",
  "selectItems": "count"
}

Host detail metrics:
method: "item.get"
params: {
  "output": ["itemid","name","lastvalue",
             "units","lastclock"],
  "hostids": ["{hostid}"],
  "monitored": true,
  "limit": 30
}

Historical charts:
method: "history.get"
params: {
  "output": "extend",
  "history": 0,
  "itemids": ["{itemid}"],
  "time_from": {now - 21600},
  "time_till": {now},
  "limit": 100
}

USER MANAGEMENT (Admin only):
method: "user.get"
params: {
  "output": ["userid","username","name",
             "surname","roleid","type"],
  "selectRole": ["roleid","name"]
}
→ Display in Settings → User Management
→ Show role badge per user based on type field

ERROR HANDLING:
  -32602 → session expired → redirect Login
  Network timeout (10s) → offline banner
  Any error → inline retry button
  Log all errors with method name
